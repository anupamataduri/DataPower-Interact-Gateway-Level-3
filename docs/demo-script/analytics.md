# Analytics

IBM DataPower Interact Gateway provides unified observability across all AI-driven interactions. In this section, we explore the analytics capabilities available in the platform — from individual API event details and latency analysis to AI Platform reports, MCP usage, LLM token consumption, and gateway operations. These views allow teams to monitor activity, understand access patterns, and govern AI usage at runtime.
